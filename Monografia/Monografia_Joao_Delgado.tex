	\chapter*{Resumo}
	\thispagestyle{empty}
	Este trabalho é um estudo sobre metaestabilidade, se guiando desde o entendimento de propriedades de probabilidade até os conceitos de mataesbilidade com uma abordagem de potênciais. Foi utilizado simulações de processos como o andar do bêbado em $N$ dimensões e um caminhar metaestável com quatro estados, com o objetivo de ilustrar fenômenos de mataesbilidade. Utilizando modelos que exploram a evolução de sistemas aleatórios ao longo do tempo, destacando propriedades como convergência de estado e permanência prolongada em regiões específicas do espaço de estados. Por meio de visualizações dinâmicas, evidencia-se como a dinâmica local e a estrutura global de um sistema sistema influenciam o comportamento macroscópico, contribuindo para a compreensão de conceitos fundamentais de Cadeias de Markov e Mecânica Estatística.

	\chapter*{Abstract}
	\thispagestyle{empty}
	This work is a study on metastability, following from the understanding of probability properties to the concepts of mortality with a protecial approach. Simulations of processes such as the drunken walk in $N$ dimensions and a metastable walk with four states are used, in order to illustrate phenomena of metastablyship. Using models that explore the evolution of random systems over time, properties such as convergence between distinct configurations and prolonged permanence in specific regions of state space are highlighted. Through dynamic visualizations, it is evident how the local dynamics and the global structure of a system influence the macroscopic behavior, contributing to the understanding of fundamental concepts of Markov chains and Static Mechanics.

	\chapter*{Introdução}\label{Introdução}
A metaestabilidade é um fenômeno que surge em diversos contextos, especialmente no estudo de sistemas dinâmicos e probabilísticos. Sua investigação ganhou notoriedade a partir da necessidade de compreender comportamentos aparentemente estáveis em sistemas que, a longo prazo, sofrem transições abruptas entre estados. Historicamente, esse tema está associado ao desenvolvimento da teoria das probabilidade, da Mecânica Estatística e das cadeias de Markov, áreas impulsionadas por problemas oriundos tanto da Física quanto da matemática pura. Contribuições fundamentais de diversos pesquisadores ao longo do século XX permitiram a consolidação dessas ideias, estabelecendo as bases teóricas para o estudo rigoroso da metaestabilidade.

De forma geral, a metaestabilidade descreve situações em que um sistema permanece por longos períodos em estados que não são verdadeiramente estáveis, mas que apresentam uma estabilidade aparente antes de ocorrer uma transição para um estado mais estável. Esse comportamento é particularmente relevante em modelos probabilísticos, nos quais a análise do tempo de permanência e das transições entre estados desempenha um papel central. Assim, o estudo da metaestabilidade torna-se essencial para a compreensão de fenômenos complexos, com aplicações que vão desde processos físicos até algoritmos estocásticos.

Neste trabalho, serão apresentados inicialmente conceitos fundamentais necessários para o desenvolvimento do tema, com destaque para noções básicas de probabilidade e cadeias de Markov. Em seguida, será abordado um modelo específico de sistema em tempo discreto definido em um reticulado (\textit{lattice}), com base em uma aula ministrada pelo professor Peixoto em um colóquio do IMPA, que servirá como motivação e exemplo concreto do fenômeno estudado. Por fim, será explorada uma abordagem baseada em potenciais, fundamentada no artigo de Claudio Landim, permitindo uma análise mais aprofundada das propriedades metaestáveis e de suas implicações teóricas.

\chapter{Noções básicas de medida e probabilidade}
Nesse capítulo vamos falar das noções iniciais de probabilidade para que possamos compreender os processos de metaestabilidade. Inicialmente falaremos da construção da $\sigma$-álgebra e as consequências de imbuir esse objeto com uma medida, assim seguindo para a construção da medida de probabilidade. Em sequência, falamos um sobre as propriedades das cadeias de Markov, que são um dos objetos mais importantes quando falamos de metaestabilidade.
\begin{Def} Uma álgebra de um conjunto $\Omega$ é uma classe $\algebra$ de subconjuntos de $\Omega$ tal que:
	\begin{enumerate}[i.]
		\item $\Omega \in \algebra$,
		\item $A \in \algebra$ implica que $A^{c} \in \algebra$,
		\item $A,B \in \algebra$ implica que $A\cup B \in \algebra$.
	\end{enumerate}
\end{Def}
Uma álgebra é uma classe que se pode realizar operações elementares de conjuntos, o que é característica muito boa, pois como funções trabalham com conjunto e, sem esses objetos, ficamos muito restritos ou até de mãos atadas ao desenvolver uma teoria. Contudo, a álgebra ainda não é uma estrutura adequada para trabalhar com probabilidade, pois, apesar das uniões de dois elementos da álgebra estarem na álgebra, a união infinitesimal desses elementos pode não estar no conjunto. Logo, precisamos de uma estrutura que seja fechada para uniões enumeráveis.
\begin{Def} Uma $\sigma$-álgebra é uma álgebra fechada por uniões enumeráveis, ou seja,
	\begin{enumerate}[iv.]
		\item $A_{j} \in \algebra$ tal que $j = 1, 2, \ldots $  implica que $\displaystyle \bigcup^{\infty}_{j=1}A_{j} \in \algebra$.
	\end{enumerate}
\end{Def}
\begin{Exem}
	Um exemplo básico de uma $\sigma$-álgebra é o que corresponde ao lançamento de um dado de 6 lados honesto. O nosso conjunto de estudo seria os lados do dado, $D = \{1,2,3,4,5,6\}$ e nossa $\sigma$-álgebra é $\sigAlgebra = \mathcal{P}(D)$, as partes de $D$.
\end{Exem}
\begin{Def}[$\sigma$-álgebra gerada por uma classe de subconjuntos] Seja $\mathcal{E}$ uma classe de subconjuntos de $\Omega$. Então definamos $\sigma (\mathcal{E})$ como a única $\sigma$-álgebra gerada por $\mathcal{E}$ que satisfaz:
	\begin{enumerate}[i.]
		\item $\sigma(\mathcal{E}) \text{ é } \sigma$-álgebra,
		\item $\mathcal{E} \subseteq \sigma (\mathcal{E})$,
		\item Se $\sigAlgebra$ é $\sigma$-álgebra $\mathcal{E} \subseteq \sigAlgebra$, então implica que $\sigma(\mathcal{E}) \subseteq \sigAlgebra$.
	\end{enumerate}
\end{Def} 
\begin{Exem}
	Ainda pensando no dado, tomemos uma classe de conjuntos $\mathcal{E} = \{\{1,2\}\}$. Podemos criar uma $\sigma\text{-álgebra }, \sigma(\mathcal{E})$, adicionando ${D, \{1,2\}, \varnothing, \{3,4,5,6\}}$ em $\sigma(\mathcal{E})$, logo temos $\sigma(\mathcal{E}) = \{D, \varnothing, \{1,2\}, \{3,4,5,6\}\}$. Perceba que as uniões dois-a-dois são fechadas, então $\sigma(\mathcal{E})$ é $\sigma\text{-álgebra}$.
\end{Exem}
Criado o nosso espaço onde vamos estudar (espaços mensuráveis), podemos começar a elaborar à ideia de probabilidade.
\begin{Def}
	Uma medida em um espaço mensurável, $(\Omega, \sigAlgebra)$, é uma função $\mu : \sigAlgebra \rightarrow [0, + \infty]$ que satisfaz:
	\begin{enumerate}[i.]
		\item $\mu(\varnothing) = 0$,
		\item $\displaystyle \mu \left(\bigcup^{\infty}_{i=1}A_{i} \right) = \sum^{\infty}_{i=1}\mu(A_{i})$ para todo $A_{i} \in \sigAlgebra$ dois a dois disjuntos.
	\end{enumerate}
	A tripla $(\Omega, \sigAlgebra, \mu)$ denomina-se espaço de medida.
\end{Def}

Observe que isso inclui somas finitas, pois podemos considerar os $A_{n}$ tal qual para todo $n > n_{0}$ é igual a $\varnothing$. Um exemplo importante de medida é a delta de Dirac:
\begin{Exem}
	Seja $\Omega$ um conjunto e consideremos $\mathcal{P}(\Omega)$, as partes de $\Omega$, então dado um $p \in \Omega$, seja a função $\delta_{p}: \mathcal{P}(\Omega) \rightarrow [0, +\infty]$:
	$$
	\delta_{p}(A) =
	\begin{cases}
		1, & \text{se } p \in A;\\
		0, & c.c.
	\end{cases}
	$$
\end{Exem}

Vamos agora ver algumas propriedades das medidas que não são nenhuma surpresa, mas que precisamos formular.
\begin{Teo}
	Seja $(\Omega, \sigAlgebra, \mu)$ um espaço de medida e $A,B, A_{1}, A_{2}, ... \in \sigAlgebra$.
	\begin{enumerate}[1.]
		\item $\mu(A^{c}) = \mu(\Omega) - \mu(A)$, \label{eq:teo1.I}
		\item Se $A \subseteq B,\text{ então vale que }\mu(A) \menor \mu(B)\text{ e }\mu(B \setminus A) = \mu(B) - \mu(A)$,
		\item $\mu(A \cup B) = \mu(A) + \mu(B) - \mu(A \cap B)$,
		\item $\displaystyle \mu \left(\bigcup^{\infty}_{n=1}(A_{n}) \right) \menor \sum_{n=1}^{\infty}\mu(A_{n})$,
		\item Se $\mu(A_{n}) < \infty$, $A_{n}\uparrow A$ ou $A_{n}\downarrow A$, então $\mu(A_{n})\rightarrow \mu(A)$.
	\end{enumerate}
\end{Teo}


\begin{proof}
	\begin{enumerate}[1.]
		\item Como $\Omega = A \cup A^{c}$, temos que $\mu(\Omega) = \mu(A \cup A^{c}) = \mu(A) + \mu(A^{c})$.
		\item Como $A \subseteq B$, então  $B = A \cup B \setminus A \Rightarrow \mu(B) = \mu(A \cup B \setminus A) = \mu(A) + \mu(B \setminus A) \Rightarrow \mu(B \setminus A) = \mu(B) - \mu(A)$.
		\item Usando o item (ii) temos que $\mu(A \cup B) = \mu(A) + \mu(B \setminus A)$. Como $\mu(B) = \mu(B \setminus A) + \mu(A \cap B)$, então $\mu(A \cup B) = \mu(A) + \mu(B) - \mu(A \cap B)$.
		\item A partir de uma sequência de $A_{n}$ podemos criar uma sequência disjunta. Seja $B_{1} = A_{1}\text{, } B_{2} = A_{2} \setminus A_{1}\text{, } B_{3} = A_{3}\setminus(A_{2} \cup A_{1})$, etc. Ou seja, $B_{n} = A_{n}\setminus (\bigcup^{n-1}_{j=1}A_{j})$, perceba que $B_{n}$ é uma sequência de conjuntos disjunto. Assim $\displaystyle \mu \left(\bigcup^{\infty}_{n=1}A_{n} \right) = \mu \left(\bigcup^{\infty}_{n=1}B_{n} \right) = \sum^{\infty}_{n=1}\mu(B_{n}) \menor \sum^{\infty}_{n=1}\mu(A_{n})$.
		\item Suponhamos que $A_{n}\uparrow A$, então $A_{n} \subset A_{n+1}$. Como é uma sequência de conjuntos arbitrário, a fim de obter melhor controle, podemos criar uma sequência $B_{n}$ de conjuntos disjunto tal que $\bigcup^{\infty}_{n} B_{n} = \bigcup^{\infty}_{n} A_{n}$, definindo $B_{n} = A_{n}/A_{n-1}$ sendo $A_{0}$. Fixe um  $k \in \mathbb{N}$ e  $i \maior 1$. Daí, $\displaystyle \bigcup^{k}_{i} B_{i} = \bigcup^{k}_{i}(A_{i}/A_{i-1})$ nos leva a 
		\begin{align*}
			\mu \left(\bigcup^{k}_{i} B_{i}\right) &= \mu \left(\bigcup^{k}_{i} (A_{i} \setminus A_{i-1})\right), \\
			& = \sum^{k}_{i}\mu(A_{i} \setminus A_{i-1}),\\
			&= \sum^{k}_{i}(\mu(A_{i}) - \mu(A_{i-1})).
		\end{align*}
		\newpage %PARA AJUSTAR ESPAÇAMENTO DO PARAGRAFO.
		Como o lado direito da equação é uma soma telescópica, temos que $\mu(\bigcup^{k}_{i} B_{i})  = \mu(A_{k}) - \mu(A_{0})$. Logo, \vspace{-10pt} 
		\begin{align*}
			&\lim_{k \to \infty} \mu \left(\bigcup^{k}_{i} B_{i}\right) = \lim_{k \to \infty}\mu(A_{k}),\\
			&\Rightarrow \mu \left(\bigcup^{\infty}_{i} B_{i}\right) = \mu\left(\bigcup^{\infty}_{i} A_{i}\right) = \mu(A).
		\end{align*}
		Para provar $A_{n} \downarrow A$, podemos utilizar o que acabamos de provar. Tome a sequência $A^{c}_{n} \uparrow A^{c}$ e lembrando que $P(A_{n}) = 1 - P(A^{c}_{n})$, então se $n \to \infty$ temos que $\displaystyle \lim_{n \to \infty} P(A_{n}) = 1 - P(A^c{})$.
	\end{enumerate}
\end{proof}
Agora que entendemos um pouco sobre medidas e $\sigma$-álgebras, podemos começar a adentrar no assunto de probabilidade. Contudo o que seria uma probabilidade? É intuitivo pensar que probabilidade satisfaça as definição de medida, pois com esse objeto temos o intuito de medir quão provável um evento pode ocorrer.
\begin{Def}\hypertarget{Definição 5} Seja $(\Omega, \sigAlgebra, \mu)$ um espaço de medida. Se $\mu: \sigAlgebra \rightarrow \mathbb{R}$  é uma função  que satisfaz:
	\begin{enumerate}[i.]
		\item $\mu(\Omega) = 1$,
		\item $\displaystyle \mu\left(\bigcup_{i=1}^{\infty} A_{i}\right) = \sum^{\infty}_{i=1}\mu(A_{i})$ para todo $A_{i} \in \sigAlgebra$ dois a dois disjuntos.
	\end{enumerate}
	Então $\mu$ é dita uma medida de probabilidade. Uma tripla $(\Omega, \sigAlgebra, \mu)$ denomina-se espaço de probabilidade.
\end{Def}
Perceba que pela afirmação\ref{eq:teo1.I}, temos que $\mu(\Omega) = 1 - \mu(\varnothing) = 1$. Logo, essa definição para probabilidade $\mu$, nos diz que também é medida, assim tudo que vimos para medida vale para probabilidade.

Seja $(\Omega, \sigAlgebra, \mu)$ um espaço de probabilidade. Tome dois eventos $A,B \in \sigAlgebra$ tais que $\mu(A) = a$ e $\mu(B) = b$. Qual é a probabilidade do evento acontecer $A$ se sabemos que o evento $B$ acontece?

\begin{Def}\label{def5} Seja $(\Omega, \sigAlgebra, \mu)$ um espaço de probabilidade e $A,B \in \sigAlgebra$ tal que $\mu(B)>0$. Uma probabilidade condicional de $A$ dado $B$ é $\mathbb{P}: \sigAlgebra \rightarrow \mathbb{R}$
	
	$$ \mathbb{P}(A|B) = \dfrac{\mu(A \cap B)}{\mu(B)}.$$
Quando $\mu(B)=0$, então definimos $\mathbb{P}(A|B) = \mathbb{P}(A)$.
\end{Def}
A probabilidade condicional diferente da noção usual de probabilidade, contextualiza as chances de um evento acontecer. Perceba que quando $\mathbb{P}(B)>0$, a primeira nada mais é do que relativização da probabilidade do evento $A$ para o evento $B$. Veja que estamos falando de eventos, elementos da $\sigma$-álgebra e não qualquer subconjunto de $\Omega$.
\begin{Teo}[Regra do produto] Em $(\Omega, \sigAlgebra, \mu)$. Dados os eventos $A_{1}, A_{2}, \ldots , A_{n} \in \sigAlgebra$,
	$$\mathbb{P}\left( \bigcap^{n}_{i=1} A_{i}\right) = \mathbb{P}(A_{1})\mathbb{P}(A_{2}|A_{1})\mathbb{P}(A_{3}|A_{1} \cap A_{2}) \text{{ \large . . . }} \mathbb{P}\left(A_{n} \left| \ \bigcap^{n-1}_{i=1} A_{i}\right. \right). $$
\end{Teo}

\begin{Def}[Eventos independentes] Seja $A,B \in \sigAlgebra$ são independentes se 
	$$\mathbb{P}(A \cap B)= \mathbb{P}(A)\mathbb{P}(B). $$
\end{Def}
Logo, se a sequência de eventos $A_{i}$ são independentes, então $\displaystyle \mathbb{P}\left( \bigcap^{n}_{i=1} A_{i}\right) = \prod_{i=1}^{n}\mathbb{P}(A_{i})$, pois $\mathbb{P}(A_{j} | A_{i}) = A_{j}$.

\section{Cadeia de Markov}
\begin{Def}[Cadeia de Markov finita] Seja $\left (\Omega, \sigma \{ \Omega \}, \mathbb{P} \right)$ um espaço de probabilidade e $\left( X_{1}, X_{2}, X_{3}, ... \right)$ uma sequência aleatória de variáveis que satisfaz, juntamente com uma matriz de transição $\mathbb{P}$, a propriedade de Markov, definida da seguinte forma: Se para $\forall x,y \in \Omega$, para todo $t \maior 1$, e para todo evento $H_{t-1} = \displaystyle \bigcap^{t-1}_{s=0} \left\{ X_{s} = x_{s}\right\}$ satisfaz $\mathbb{P} \left(H_{t-1} \bigcap \left\{ X_{t} = x \right\} \right) > 0$, nos temos que
	$$\mathbb{P} \left\{ X_{t+1} = y | H_{t-1} \bigcap \left\{ X_{t} = x \right\} \right\} =  \mathbb{P} \left\{ X_{t+1} = y | \left\{ X_{t} = x \right\} \right\}.$$
\end{Def}
Em termos mais amigáveis, a probabilidade de a sequência chegar a um determinado estado depende apenas do estado anterior, podemos pensar nisso como uma sequência que apresenta perda de memória. Como estamos trabalhando com probabilidade, a soma das chances de transição de um estado para todos os outros deve ser igual a 1. Por isso, a nossa matriz de transição precisa ser estocástica.
\begin{Def}[Matriz estocástica] Denominamos $P$ de matriz estocástica, se as suas entradas são não-negativas e a soma de elementos de cada coluna da matriz é igual a um, isso é, $\Sum_{j \in | \Omega | } P_{ij} = \mathbb{P}(x, \cdot)= 1 \ \forall x \in \Omega$.
\end{Def}

Em muitos casos gostaríamos de trabalhar com distribuições de pontos diferentes do espaço, $\mathbb{P}(x, \cdot), \mathbb{P}(y, \cdot)$, então para facilitar a compreensão, vamos utilizar a notação $\mathbb{E}_{x}, \mathbb{P}_{x}$.
$$\mathbb{E}_{x}(f(X_{1})) = \sum_{y}f(y)\mathbb{P}_{x} \left( X_{1} = y \right) = \sum_{y} f(y)\mathbb{P}(x,y) = \mathbb{P}f(X). $$
tal que $f$ é uma função. Notação: $\mathbb{P}_{x}(X_{t} = y) = (\delta_{x} \mathbb{P}^{t})(y) = \mathbb{P}^{t}(x,y)$.
\section{Função de representação aleatória}
\begin{Def}[Função de representação aleatória de uma matriz $P$ em um espaço de estados $\Omega$]
A função $f$ é uma representação aleatória se $f: \Omega \times \Lambda \rightarrow \Lambda$, onde $\Lambda$ são os valores da variável aleatória $Z$ definida em $\Omega$, satisfaz
$$\mathbb{P}(f(x, Z(x)) = Y) = \mathbb{P}(x, y).$$
\end{Def}

A função de representação é uma ótima ferramenta para substituirmos a matriz de transição quando temos uma quantidade extensa de estados tornando as operações laboriosas. Seja uma sequência de variáveis $(Z_{n})_{n}$ iid's com mesma distribuição de $Z$ e $X_{0}$ com distribuição $\mu$, podemos definir uma sequência de variáveis aleatórias $(X_{n})_{n}$ como
$$X_{n} = f(X_{n-1}, Z_{n}) \ n \maior 1,$$
tal que essa sequência é uma cadeia de Markov com uma matriz de transição $P$ com distribuição $\mu$.
\begin{Prop}
	Toda matriz de transição em um espaço de Markov finito tem uma função de representação aleatória.
\end{Prop}

\begin{proof}
	Seja $P$ uma matriz de transição de um espaço de Markov com o espaço de estados $\Omega = \{x_{1}, x_{2}, \ldots, x_{n} \}$ e seja $\Lambda = [0,1]$, onde as variáveis aleatórias auxiliares $Z, Z_{1}, Z_{2}, \ldots$ são iid's nesse intervalo. Definamos $F_{ij} = \Sum^{j}_{k=1} \mathbb{P}(x_{i}, x(k))$, então podemos definir $f$ como $f(x_{i}, Z) := x_{j}$ quando $F_{i, j-1} < Z < F_{i, j}$. Portanto,
	$$\mathbb{P}\{f(x_{i}, Z) = x_{j}\} = \mathbb{P}\{F_{i, j-1} < Z < F_{i, j}\} = \mathbb{P}(x_{i}, x_{j}).$$
\end{proof}
Veremos em seguidas algumas propriedades dessas cadeias de Markov que nos permite extrair algumas informações.  
\begin{Def}[Irredutível] Seja $P$ uma cadeia, se para todo $x,y \in \Omega$, existe um inteiro $t$ tal que $\mathbb{P}^{t}(x,y) > 0$.
\end{Def}

\begin{Def}[Período de $x$] Definamos o conjunto $T(x) = \{t \maior 1 : \mathbb{P}^{t}(x,x) > 0 \}$. O período de $x$ é o maior divisor comum $( \operatorname{mdc}$ de $T(x))$.
\end{Def}
\begin{Prop}Se $P$ é irredutível, então $\operatorname{mdc}(T(x)) = \operatorname{mdc}(T(y))$ para $x,y \in \Omega$.
\end{Prop}
\begin{proof}
	Seja $k \in T(x)$. Sabemos que existe $r$ e $l$ tal que $\mathbb{P}^{r}(x,y)>0$ e $\mathbb{P}^{l}(x,y)>0$. Seja $m = r + l$, é direto ver que $m \in T(x) \cap T(y)$.
	Provaremos que $k + m \in T(y)$,
	\begin{align*}
		\mathbb{P}^{k + m}(x,x) &= \mathbb{P}^{k}(x,x)\mathbb{P}^{r}(x,y)\mathbb{P}^{l}(y,x) \\
		&= \mathbb{P}^{l}(y,x)\mathbb{P}^{k}(x,x)\mathbb{P}^{r}(x,y) \\
		&= \mathbb{P}^{l + k + r}(y,y) = \mathbb{P}^{m + k}(y,y).
	\end{align*}
	Então $k+m \in T(y)$, então $k \in \{n - m : n \in T(y) \} \ \Rightarrow T(x) \subset T(y) - m$. Portanto, como $m \in T(y)$, $\operatorname{mdc}T(y)$ divide todo elemento de $T(x)$, consequentemente $\operatorname{mdc}(T(y)) \menor \operatorname{mdc}(T(x))$. Para $\operatorname{mdc}(T(x)) \menor \operatorname{mdc}(T(y))$ é análogo. Portanto, $\operatorname{mdc}(T(y)) = \operatorname{mdc}(T(x))$.
\end{proof}
\begin{Def}[Aperiódico]
Se em uma cadeia o $\operatorname{mdc}(T(x)) \ \forall x \in \Omega$ é $1$, então denominamos aperiódico. Se a cadeia não é aperiódico, então é periódico.
\end{Def}
\begin{Prop}\label{prop:1.3}
Se $P$ é irredutível, então existe um inteiro $r$ tal que $\mathbb{P}^{r}(x,y) > 0$ para $\forall x,y \in \Omega$.
\end{Prop}

\begin{proof}
	Antes de provar essa proposição, iremos demonstrar um lema que nos garantirá que a partir de um inteiro vai ser possível o retorno de um $x \in \Omega$.
	\begin{Lema}
		Seja $S \subset \mathbb{Z}^{+}$ tal qual é fechado por adição e de $\operatorname{mdc}(S) = 1$, então existe $m_{s} \in \mathbb{Z}^{+}$ tal que para todos $m \maior m_{s}$ pode ser escrito como combinação linear de elementos de $S$.
		\begin{proof}
			Como o $\operatorname{mdc}(S) = 1$, podemos aplicar o Teorema de Bézout.
			Seja $a,b \in S, \exists x,y \in \mathbb{Z}, ax + by = 1$. O caso de $x,y \maior 0$, então está feito. O caso de $x,y < 0$, não ocorre, pois $a,b \menor 0$. Então só nos resta o caso de $x > 0$ e $y < 0$ ou contrário.
			Suponhamos que $y > 0$ e $x < 0$, e seja $k \in \mathbb{Z}^{+}$, logo $\exists r,q \in \mathbb{Z}^{+} (k = aq + r \ \land \ a \maior r \maior q)$.
			\begin{align*}
				1 &= xa + yb \\
				r &= rxa + ryb, \\
				k = aq + r &= rxa + aq + ryb \\
				k &= (rx + q)a + ryb.
			\end{align*}
			Como $y > 0$ e $r \menor 0$, então só precisamos verificar $xr + q$. Lembrando que $x < 0$, logo $(-x) > 0$.
			$$xr + q > 0 \Leftrightarrow q > (-x)r.$$
			Como $a > r$, então $q > (-x)a$.
		\end{proof}
	\end{Lema}
	Agora, podemos provar a Proposição \ref{prop:1.3}. Vamos provar que $\forall x \in \Omega$, $T(x)$ é fechado por adição. Seja $a,b \in T(x)$, $\mathbb{P}^{a+b}(x,x) = \mathbb{P}^{a}(x,x)\mathbb{P}^{b}(x,x) > 0$, então $a+b \in T(x)$. Logo, pelo lema anterior, sabemos que existe $t_{x}$ tal que $t \maior t_{x}$, $\mathbb{P}^{t_{x}}(x,x) > 0$. Como sistema é irredutível, então existe um inteiro $k = k(x,y)$ tal que $\mathbb{P}^{k}(x,y) > 0$. Logo, fixado x, seja $t = t_{x} + r(x,y)$,
	$$\mathbb{P}^{t}(x,y) \maior \mathbb{P}^{t_{x}}(x,x)\mathbb{P}^{r(x,y)}(x,y) > 0.$$
\end{proof}

\section{Passeio aleatório em grafos}

Um grafo $G = (V, E)$ consiste em um conjunto de vértice $V$ e um conjunto de aresta $E$, onde $E \subset \{ \{x, y\} : x,y \in V \text{ e } x \neq y \}$ e $V$ é o conjunto de pontos tal que para cada par de ponto ligados por um linha. Denotando $\{x,y\} \in E$ como $x \sim y$, chamamos $y$ de vizinhança de $x$. E o total de vizinhança de $x$ como o grau de $x$, ou seja, $| \{ x \sim y: y \in V \}| = \deg(x)$.

Como um exemplo inicial, podemos definir um grafo e criar uma função de probabilidade a partir da vizinhança de um ponto, tornando a escolha de um vértice pular para outro, ser uniforme.
\begin{align}
	\mathbb{P}(x,y) =
	\begin{cases}
		\dfrac{1}{\deg(x)} ; \text{ se } x \sim y, \NT \\
		0 ; \text{ c.c}.
	\end{cases}
\end{align}

\section{Distribuição estacionária}
Em caminhadas aleatórias podemos andar tanto e acabar tendendo a algum lugar. Assim, se verificarmos que a distribuição de uma caminhada aleatória está tendendo para algum lugar, então dizemos que ela é estacionária.
\begin{Def}
	Seja $P$ uma matriz de transição em grafo $G$. Definimos como uma distribuição estacionária, quando uma medida de probabilidade $\pi$ satisfaz
	$$ 
	\pi = \pi P.
	$$
	De forma equivalente podemos reescrever nossa definição como
	$$ 
	\pi(y) = \Sum_{x \in V } \pi(x) P(x,y).
	$$
\end{Def}

\begin{Exem}
	Utilizando o simples andar aleatório sobre um grafo $G = (V,E)$. Para qualquer $y \in V$
	$$ 
	\Sum_{x \in V } \deg(x) P(x,y) = \Sum_{x \sim y} \dfrac{\deg(x)}{\deg(x)} = \deg(y) 
	$$
	Utilizando como normalizador $\Sum_{y \in V} \deg(y) = 2|E|$, podemos dizer que a medida de probabilidade
	$$
	\pi(y) = \dfrac{\deg(y)}{2|E|} \hspace{0.5cm} \forall \ y \ \in V
	$$ 
	é uma distribuição estacionária.
\end{Exem}

 O Teorema\ref{thm:teorema_1} nos dá uma estimativa do crescimento do tempo que leva para dois pontos do hipercubo se encontrarem quando $N \to \infty$.


\begin{Teo}\label{thm:teorema_1}
	Seja $t^{-}_{N} = \inf(t > 0 : \sigma^{+}(t) = \sigma^{-}(t))$. Então,
	$$\lim_{N \to \infty} \mathbb{P}\left( \left| \dfrac{t^{-}_{N}}{N \log N} - 1 \right| > \varepsilon \right) = 0, \forall \varepsilon > 0. $$
\end{Teo}

\begin{proof}
Para provar o teorema é suficiente mostrar que $$\displaystyle \lim_{N \to \infty} \mathbb{P} \left( \dfrac{t^{-}_{N}}{N\log N} \right) = 1.$$
\par Seja $\displaystyle D_{N}(t) = \dfrac{1}{2N} \sum^{N}_{i = 1} \left| \sigma_{i}^{+}(t) - \sigma_{i}^{-}(t) \right|$ a distância no instante $n$ entre $\sigma^{+}$ e $\sigma^{-}$. Pela evolução de $\sigma(t)$ temos que $D_{N}(t)$ é uma cadeia de Markov em $\{0, \tfrac{1}{N}, \dotsc, \tfrac{N - 1}{N}, 1 \}$ sendo a probabilidade de transição dada por:

\[
\mathbb{P}_{xy} =
\begin{cases}
\ 1 - x &,se \ y = x, \\
\ x &,se \ y = x - \tfrac{1}{N},\\
\ 0 &, \ c.c.
\end{cases}
\]

Definimos $\displaystyle t^{-}_{N} = \sum^{N}_{k = 1} \lambda{k}$, onde $\lambda_{1} = 1$ e $\lambda_{k}$ são variáveis aleatórias de geométricas de parâmetros $p_{k} = 1 - \tfrac{k - 1}{N}$. $\lambda_{k}$ são o menor tempo que o processo $D_{N}(t)$ demora para sair de $1 - \tfrac{k - 1}{N}$ para $1 - \tfrac{k}{N}$.

Vamos ver a esperança:
\begin{align*}
\mathbb{E} (\lambda_{k}) &= \sum^{\infty}_{n} \mathbb{P}(\lambda_{k} = n) \cdot n, \\
&= 1 \cdot p_{k} + 2 \cdot p_{k}(1 - p_{k}) + 3 \cdot p_{k}(1 - p_{k})^{2} + \dotsc
\end{align*}
Como $\mathbb{E}(\lambda_{k}) \cdot (1 - p_{k}) = 1 \cdot p_{k}(1 - p_{k}) + 2 \cdot p_{k}(1 - p_{k})^{2} + 3 \cdot p_{k}(1 - p_{k})^{3} + \dotsc$
\begin{align*}
\mathbb{E}(\lambda_{k}) - (1 - p_{k}) \cdot \mathbb{E}(\lambda_{k}) &= p_{k} + p_{k} \cdot (1 - p_{k}) + p_{k} \cdot (1 - p_{k})^{2} + \dotsc, \\
p_{k}\mathbb{E}(\lambda_{k}) &= p_{k}(1 + (1 - p_{k}) + (1 - p_{k})^{2} + \dotsc ), \\
\mathbb{E}(\lambda_{k}) &= (1 + (1 - p_{k}) + (1 - p_{k})^{2} + \dotsc ), \\
&= \dfrac{1}{1 - (1 - p_{k})} = \dfrac{1}{p_{k}} = \dfrac{N}{N + 1 - k}.
\end{align*}
Agora vamos observar a variância:

$$\var (\lambda_{k}) = \mathbb{E}(\lambda_{k} - \mathbb{E}(\lambda_{k}))^{2} = \mathbb{E}(\lambda_{k}^{2}) - \mathbb{E}(\lambda_{k})^{2}.$$

\noindent Vamos obter $\mathbb{E}(\lambda^{2})$:
\begin{align*}
\mathbb{E}(\lambda_{k}^{2}) &= \sum^{\infty}_{x} x^{2} \cdot \mathbb{P}(\lambda_{k} = x) = \sum^{\infty}_{x} x^{2} \cdot (1 - p_{k})p_{k}^{x - 1}, \\
&= \sum^{\infty}_{x} x^{2} q^{x - 1}p_{k} = p_{k} \sum^{\infty}_{x} x\frac{d}{dq_{k}}q_{k}^{x}.
\end{align*}
Sendo $q_{k} = (1 - p_{k})$.
\begin{align*}
\mathbb{E}(\lambda_{k}^{2}) &= p_{k}\frac{d}{dq_{k}} \cdot q \sum^{\infty}_{x} x \cdot q_{k}^{x - 1} = p_{k}\frac{d}{dq_{k}} \cdot q \sum^{\infty}_{x} \frac{d}{dq_{k}} q_{k}^{x}, \\
&= p_{k}\frac{d}{dq_{k}} \cdot q \cdot \frac{d}{dq_{k}}\sum^{\infty}_{x} q_{k}^{x} = p_{k}\frac{d}{dq_{k}} \cdot q \cdot \frac{d}{dq_{k}} \cdot \left( \frac{q_{k}}{1 - q_{k}} \right), \\
&= p_{k} \left( \frac{1 + q_{k}}{(1 - q_{k})^{2}}\right) = \frac{2 - p_{k}}{p_{k}^{2}}.
\end{align*}
Assim,
$\var(\lambda_{k}) = \tfrac{2 - p_{k}}{p_{k}^{2}} - \tfrac{1}{p_{k}^{2}} = \tfrac{1 - p_{k}}{p_{k}^{2}}$. Substituindo $p_{k} = 1 - \tfrac{k - 1}{N}$, temos
$\var = \tfrac{N(k - 1)}{(N + 1 - k)}$.

Logo,
\begin{align*}
\mathbb{E}(t^{-}_{N}) &= \mathbb{E}\left( \sum^{N}_{k = 0} \lambda_{k} \right) = \sum^{N}_{k = 0} \dfrac{N}{N + 1 - k}, \\
&= N\sum^{N}_{k = 0} \dfrac{1}{N + 1 - k} = N \sum^{N}_{k = 1} \dfrac{1}{k}.
\end{align*}
Como $\displaystyle \int^{N}_{1} \dfrac{1}{x} \, dx = \log N$, então $\displaystyle N \log (N - 1) \menor \mathbb{E}(\lambda_{k}) = N \sum^{N}_{k = 1} \dfrac{1}{k} \menor N \log(N)$.

\noindent Quando $n \to \infty$, $\mathbb{E}(t^{-}_{N}) \sim N \log (N)$. Logo, pela desigualdade de Tchebyshev:
\begin{align}
\mathbb{P}(t^{-}_{N} - \mathbb{E}(t^{-}_{N}) | \varepsilon \cdot \mathbb{E}(t^{-}_{N})) \menor \dfrac{\var(t^{-}_{N})}{\varepsilon^{2} \cdot \mathbb{E}(t^{-}_{N})} &=\dfrac{\sum^{N}_{k=1} \dfrac{N(k - 1)}{(N - K + 1)^{2}}}{\varepsilon^{2}\left(\sum^{N}_{k=1} \dfrac{N}{N - K + 1} \right)^{2} }, \notag\\
&= \dfrac{N}{\varepsilon^{2} \cdot N^{2}} \cdot \dfrac{\sum^{N}_{k=1} \dfrac{(k - 1)}{(N - k + 1)^{2}}}{\left(\sum^{N}_{k=1} \dfrac{1}{N - k + 1}\right)^{2}}. \label{eq:eq1}
\end{align}
Sendo $N-1$ o maior número dos termos da soma $\Sum_{k=1}^{N} (k-1)$, então a expressão em $\left( \ref{eq:eq1} \right)$ é menor ou igual a
\begin{align}
\dfrac{N(N - 1)}{\varepsilon^{2} \cdot N^{2}} \cdot \dfrac{\sum^{N - 1}_{k=1} \dfrac{1}{k^{2}}}{\left(\sum^{N}_{k=1} \dfrac{1}{N - k + 1} \right)^{2}} 
&\menor \dfrac{N(N - 1)}{\varepsilon^{2} \cdot N^{2}} \cdot \dfrac{1 + \sum^{N - 1}_{k=2} \dfrac{1}{k^{2} - 1}}{\left( \log N \right)^{2}}, \notag \\
&\menor \dfrac{N(N - 1)}{\varepsilon^{2} \cdot N^{2}} \cdot \dfrac{1 + \dfrac{3}{4} - \dfrac{2N + 1}{2N(N + 1)}}{\left( \log N \right)^{2}}. \notag
\end{align}
Portanto,
$$\lim_{N \to \infty} \dfrac{N(N - 1)}{\varepsilon^{2} \cdot N^{2}} \cdot \dfrac{1 + \dfrac{3}{4} - \dfrac{2N + 1}{2N(N + 1)}}{\left( \log N \right)^{2}} = 0.$$
Portanto, $\displaystyle \lim_{N \to \infty} \mathbb{P}\left( \left|\dfrac{t^{-}_{N}}{\mathbb{E}(t^{-}_{N})} - 1 \right| > \varepsilon \right) = 0$.
\end{proof}

\begin{Cor}\label{thm:corolário_1}
Sejam $\sigma^{\nu}$ e $\sigma^{\zeta}$ passeios homogêneos em $H_{N}$ construídos simultaneamente, com configurações iniciais $\nu, \zeta$. Suponha para $0 \menor f \menor 1$, que $D_{N}(0) = \dfrac{[N \cdot f]}{N}$.
Então, $\displaystyle \lim_{N \to \infty} \mathbb{P}(\sigma^{\nu}(t(N)) \neq \sigma^{\zeta}(t(N))) = 0$, para qualquer $t(N)$ com $\displaystyle \lim_{N \to \infty} \dfrac{t(N)}{N \log N}= \infty$.
\end{Cor}

\begin{proof}
Primeiros notamos que
$t^{-}_{N} = \inf \{t > 0: \{I(1), \dotsc, I(t)\} \break = \{1, \dotsc, N\}\}$.
Assim,
$$\mathbb{P}(\sigma^{\nu}(t(N)) \neq \sigma^{\zeta}(t(N))) \menor \mathbb{P}(t^{-}_{N} > t(N)) \menor \dfrac{N(\log N + 1)}{t(N)}.$$
Portanto, por hipótese temos que
$$\lim_{N \to \infty} \mathbb{P}(\sigma^{\nu}(t(N)) \neq \sigma^{\zeta}(t(N))) = 0. $$
\end{proof}

\begin{Cor}\label{thm:corolário_{2}}
Seja $t(N)$ com $\displaystyle \lim_{N \to \infty} \dfrac{t(N)}{N \log N} = \infty$. Então,
$$\lim_{N \to \infty} \left|\mathbb{P}(\sigma^{+}(t(N)) = \zeta) - \dfrac{1}{2^{N}} \right| = 0, $$
para todo $\zeta \in H_{N}$.
\end{Cor}

\begin{proof}
	Vamos primeiro mostrar que $\mu$ é uma medida invariantes com respeito à evolução do passeio homogêneo.
	\begin{align*}
		\mathbb{P}(x_{1} = \zeta) &= \sum_{\nu \in H_{N}} \mathbb{P}(x_{1} = \zeta \ \vert x_{0} = \nu) \cdot \dfrac{1}{2^{N}}, \\
		&= \mathbb{P}(x_{1} = \zeta \ \vert x_{0} = \zeta) \cdot \dfrac{1}{2^{N}} + \sum^{N}_{i=1} \mathbb{P}(x_{1} = \zeta \ \vert x_{0} = \zeta^{i}) \cdot \dfrac{1}{2^{N}}, \\
		&= \dfrac{1}{2} \cdot \dfrac{1}{2^{N}} + \dfrac{1}{2} \cdot \dfrac{1}{N}\cdot \dfrac{1}{2^{N}} \cdot N
		= \dfrac{1}{2^{N+1}} + \dfrac{1}{2^{N+1}} = \dfrac{1}{2^{N}} = \mathbb{P}(x_{1} = \nu).
	\end{align*}
	Assim,
	\begin{align*}
		\left| \mathbb{P}(\sigma^{+}(t(N)) = \zeta) - \dfrac{1}{2^{N}} \right| &= \left| \mathbb{P}(\sigma^{+}(t(N)) = \zeta) - \sum_{\nu \in H_{N}} \mu(\nu) \mathbb{P}((\sigma^{\nu} = \zeta) \right|,  \\
		&\menor \sum_{\nu \in H_{N}} \mu(\nu) \left| \mathbb{P}(\sigma^{+}(t(N)) = \zeta) - \mathbb{P}(\sigma^{\nu}(t(N)) = \zeta) \right|, \\
		&\menor \sum_{\nu \in H_{N}} \sup(\mathbb{P}(\sigma^{+}(t(N)) \neq \sigma^{\nu}(t(N)))) = 0.
	\end{align*}
	A última igualdade é análoga ao corolário anterior.
\end{proof}
	Obs: Para um movimento não preguiçoso, $\xi (t)$, talvez não seja possível ocorrer um acoplamento. Se duas configurações iniciais, $\nu$ e $\zeta$, diferem em um número ímpar de coordenadas e tem esse tipo de movimentação, nunca poderá haver um acoplamento, pois a distância mínima é, $D_{N} (t) \maior \dfrac{1}{N}$.


\begin{proof}
	
	Seja $\nu$, $\phi \in H_{N}$ tal que $D^{\nu , \phi}_{N}(0) = n$ sendo $n$ um número ímpar. Vamos observar 3 situações possíveis no passeio:
	\begin{enumerate}
		\item[1)] Se $(\nu^{i}) = (\phi^{i})$, então $(n^{i})_{i} = (\phi^{i})_{i}$;
		\item[2)] Se $(\nu^{i}) \neq (\phi^{i})$, então $(n^{i})_{i} \neq (\phi^{i})_{i}$;
		\item[3)] Se $(\nu^{i}) = (\phi^{i})$, então $(n^{i})_{i} \neq (\phi^{i})_{j}$ sendo $i \neq j$.
	\end{enumerate}
	
	Se ocorrer alguns desses casos, a distância das nossas cadeias, ou se mantém a mesma ou afastam-se, mas nunca se aproximam. Logo, supondo que por ventura só alteramos as entradas que são distintas ao longo do tempo.
	Como a cada passo, $I_{\nu}(1) = i$ e $I_{\phi}(1) = j$ tal que $i \neq j$, então $D_{N}^{\nu , \phi}(1) = n - 2$ já que estamos considerando sempre o melhor dos casos, que seria mudar duas entradas diferentes. Repetindo isso várias vezes, temos que existe um $t'$ tal que $D_{N}^{\nu , \phi}(t') = 1$, pois $n$ é ímpar e a cada tempo diminuímos duas posições. Assim, caímos no caso 3), ou seja, $D_{N}^{\nu, \phi}(t) \menor \tfrac{1}{N}$.
\end{proof}
	O Teorema \ref{thm:teorema_2} nos diz que é certo que $\xi(t)$ retorna a uma posição visitada quando $N \to \infty$, além de nos mostrar que essa posição de retorno é do tipo $\xi(i)$ e $\xi(j) \ \forall i, j \menor k + 1$, e $\xi(k + 2) = \xi(k)$ para algum $k$.

\begin{Teo}\label{thm:teorema_2}
Seja $S_{N} = \inf(k > 0: \xi(k) \in \{\xi(0), \xi(1), \dotsc, \xi(k-1)\})$ e $\Gamma_{1} = \inf(k > 0: I(k) = I(k-1))$. Então, $\displaystyle \lim_{N \to \infty} \mathbb{P}[S_{N} = \Gamma_{1}] = 1$.
\end{Teo}

Para a demonstração desse teorema vamos adotar algumas definição e notações:
\begin{enumerate}
\item[1)] Seja $I$ uma variável que escolhe uma coordenada $i$ de um $\nu \in H_{N}$. Vamos denotar $I$ avaliado no tempo k como $I_{k}$.
\item[2)] $J_{1} = \{(I_{1}, I_{2}) \in \{1, 2, \dotsc, N\}^{2} : I_{1} = I_{2} \}$.
\item[3)] $\displaystyle J_{l} = \{(I_{1}, I_{2}, \dotsc, I_{2l}) \in \{1, 2, \dotsc, N\}^{2l} : \sum^{2l}_{k=1} 1_{ \{i=I_{k}\} } \in \{0, 2, 4, \dotsc, 2l\} \ \forall i \in \{1, 2, \dotsc, N\} \text{ e }  \\ (I_{1}, I_{2}, \dotsc , I_{2k}) \notin J_{k} \ \forall k \in \{1, 2, \dotsc , l - 1 \}  \}$.
\item[4)] Definimos um grupo de $i \in \{1, 2, \dotsc, N\}$ do vetor $(I_{1}, I_{2}, \dotsc, I_{2l}) \in J_{l}$ como $\{k \in \{1, 2, \dotsc, 2l-1, 2l\}: i = I(k) \}$.
\end{enumerate}
Uma foma de pensar nos vetores desses J's é ver eles como caminho na forma de laço.
\begin{Prop}\label{thm:lema_1_teo_2}
Para $l \maior 3$
$$\mathbb{P}(I_{1}, \ldots, I_{2l}) \in J_{l}) \menor \dfrac{8}{N^{3}}.$$
\end{Prop}

\begin{proof}
	Sabemos que $\mathbb{P}(I_{1}, \dotsc, I_{2l}) \in J_{l} = \dfrac{\left| J_{l} \right|}{N^{2l}}$.
	Fazendo uma estimativa superior temos que $\left| J_{l} \right| \menor 2N^{2l - 2}$, pois sendo $(I_{1}, \dotsc, I_{2l}) \in J_{l}$, então $(I_{1}, \dotsc, I_{2l - 2}) \notin J_{l-1}$, evitando a recursividade, podemos supor que $\exists i' \in \{1, \dotsc, N\}$ tal que $\displaystyle \sum^{2l - 2}_{k=1} 1_{ \{i' = I_{k}\} }$ é ímpar, como o tamanho do vetor é par, então deve $\exists i'' \neq i'$ tal que $\displaystyle \sum^{2l - 2}_{k=1} 1_{ \{i'' = I_{k}\} }$ é ímpar.
	%
	%
	% DESENHAR A FIGURA
	%
	%
	Logo, como $(I_{1}, I_{2}, \dotsc, I_{2l - 1}, I_{2l}) \in J_{l}$, então $\displaystyle \sum^{2l}_{k=1} 1_{ \{i' = I_{k}\} }$ e $\displaystyle \sum^{2l}_{k=1} 1_{ \{i'' = I_{k}\} }$ são somas pares, ou seja, os dois últimos índices são determinados pelos $i'$ e $i''$. Como $i'$ e $i''$ são diferentes, então podemos permuta-los, assim $\left| J_{l} \right| \menor 2N^{2l - 2}$.
	Podemos dividir $J_{l}$ em dois conjuntos disjuntos, $J_{l}^{''}$ e $J_{l}^{'}$, onde $J^{''}_{l}$ é o conjunto onde
	nas três últimas entradas existe duas iguais, e $J^{'}_{l}$ é o conjunto onde as três últimas entradas são distintas. Vamos achar uma estimativa superior para esse conjuntos. Em $J^{'}_{l}$ como a entrada $2l - 2$ é distinta das duas últimas e sabemos que temos dois blocos ímpares distintos que determinam as duas últimas entradas, então o bloco de $I_{2l - 2}$ no subvetor $(I_{1}, I_{2}, \dotsc, I_{2l - 3})$ é ímpar, pois se fosse o contrário, a soma $\displaystyle \sum^{2l}_{k=1} 1_{ \{I_{2l - 2} = I_{k}\} }$ seria ímpar. Logo, a entrada $2l - 2$ é determinado por um terceiro bloco ímpar. Logo, $\left| J'_{l} \right| \menor 3!N^{2l - 3}$. No conjunto $J^{''}_{l}$perceba que como $I_{2l - 1} \neq I_{2l}$, então existem somente dois casos $I_{2l - 2} = I_{2l}$ e $I_{2l - 1} = I_{2l - 2}$. Sem perda de generalidade, vamos supor que é verdade $I_{2l - 1} \neq I_{2l}$. Como ambas as duas coordenadas estão determinadas pelos mesmo bloco, então podemos lidar com esse vetor de $2l$ entradas como se fosse de $2l - 2$ entradas. Assim, $\left| J_{l}^{''} \right| \menor N \cdot \left| J^{''}_{l - 1} \right|$, pois as coordenada repetida pode ter combinação de $N$ valores. Portanto,
	$$\frac{|J_{l}|}{N^{2l}} = \frac{|J_{l}^{'}|}{N^{2l}} + \frac{|J_{l}^{''}|}{N^{2l}} \menor \frac{3!N^{2l-3}}{N^{2l}} + \dfrac{N \cdot 2N^{2l-4}}{N^{2l}} = \frac{8}{N^{3}}. $$
\end{proof}

Assim podemos definir $\E$ como a união dos $\Est{t}{N}$, ou seja, podemos pensar $\E$ como os estados de uma partícula de $0 \menor t \menor p$ sendo $p$ um inteiro. Vamos denotar $\eta_{N}(t)$ uma cadeia de Markov de tempo contínuo em $\E$ tal que o pulo de $\eta \in E_{t,N}$ para seus vértices vizinhos é uniforme, e para mudar seu estado espera um tempo exponencial. Perceba que essa cadeia de Markov é irredutível.

Dizemos que o grau de $\eta \in E_{N}$, $\deg(\eta)$, é quantidade de vizinhos. Assim conseguimos definir uma medida de probabilidade 
$$
\medpi{\eta} = \dfrac{\deg(\eta)}{Z_{N}} 
$$
onde $Z_{N} = \Sum_{\xi \in \E} \deg(\xi)$. Então, como sabemos que $\pi_{N}$ satisfaz a \textit{Equação de balanço}, a distribuição é estacionária e única.	Como síntese da evolução da cadeia de Markov, utilizaremos o \textit{Coarse-grained-model} que permite simplificar a representação do estado da partícula. Vamos denotar $\Gamma_{N} : \E \to \{0, 1, 2, 3 \}$ a projeção de uma partícula no seu tempo e $\chi$ a função característica,
$$ 
\Gamma_{N}(\eta) = \Sum_{k=0}^{3} k\chi_{\Est{k}{N}}(\eta). 
$$
Perceba que não tem problema nas intersecções dos quadrados, pois cada quadrado irá ter $(N^{d} - 1)$ vértices. A função da evolução assintótica do \textit{Coarse-grained-model} 
$$
Y_{N}(t) = \Gamma_{N}(\eta_{N}(t))
$$
é um passeio aleatório entre cubos discretos. Vamos denotar $z_{N}(t)$ o andar aleatório simétrico, de tempo contínuo em $\Lambda^{N}$, ou seja, o processo $\eta_{N}$ restrito a $\Lambda_{N}$, ademais seja $\medpi{\Lambda_{N}}$ a medida estacionária em $\Lambda_{N}$. Pelo Teorema \ref{teo:distDoisPoint}, temos que a ordem com que $z_{N}(t)$ converge para uma transição estacionária é de $N^{2}$, além disso o tempo estimado de um ponto $x$ para outro que dista $N$ é da ordem $\alpha_{N} = N^{2} \log N$ em dimensão $d = 2$ e $\alpha_{N} = N^{d}$ em dimensão $d \maior 3$.

Assumindo que iniciamos no centro de $\bb{Z}^{d}_{N}$, definimos $B$ como o conjunto dos pontos de intersecção $\Est{j}{N} \cap \Est{i}{N}$ para todo $j \neq i$. Ademais, tomemos 
$$ 
H^{N}_{B} = \inf \{ t \maior 0 :\eta_{N}(t) \in B \}.
$$
Como a ordem de $H^{N}_{B}$ é maior que a ordem de convergência da cadeia para sua estacionária, então dizemos que ela termaliza ou equilibra antes de chegar nas quinas compartilhadas. Assim podemos intuir que quanto mais perto de $B$ mais nossa partícula esquece do caminho que veio, consequentemente a probabilidade da partícula mudar de estado em $B$ se a próxima de $\tfrac{1}{2}$. Definindo uma sequência especial podemos descrever o que ocorre com a particula ao se aproximar de $\xi$. Seja $(\ell_{N} : N \maior 1)$ de números reais tais que $\ell_{N} \to \infty$ e $ \tfrac{\ell_{N}}{N} \to 0 $, criamos $V_{N}$, o conjunto dos pontos que distam até $\ell_{N}$ de $\xi$. Tomando o momento que a partícula chega a fronteira de $V_{N}$, sabemos que a ordem de tempo de sair de $V_{N}$ é $\ell^{2}_{N}\log(\ell^{2}_{N})$, uma medida muito menor que a ordem da particula alcançar o $\xi$. Assim ao adentrar em $V_{N}$ a particula realiza uma caminhada de tempo irrisório, chegando e retornando em $\xi$, passando em $E_{j,N}$ ou $E_{j \pm 1, N}$. Como o tempo de convergência da distribuição em $V_{N}$ é $\ell_{N}^{2}$, ao dentrar no quadrado, em pouco tempo o processo é termalizado.
Pensando nesse processo, como o tempo dentro de $V_{N}$ e o \textit{mixing time} são insiginificantes em relaçao a escala do tempo de escape, podemos adequadamente ignorar essa passagem por $V_{N}$ e o tempo até a convergência da distribuição, permitindo que a cadeia de Markov cresça na mesma ordem do tempo de escape $\alpha_{N}$:
$$ 
\textbf{Y}_{N}(t) = Y_{N}(t\alpha_{N}) = \Gamma_{N}(\eta_{N}(t\alpha_{N}))
$$
o qual tem imagem em $S = \{0,1,2,3\}$, composta pela cadeia $Y_{N}(t)$ de tempo contínuo de \textit{holding time} escritamente positivo e com $p(j, j \pm 1) = \tfrac{1}{2}$.

O código apresentado cria uma simulação com visualização gráfica cujo objetivo principal é ilustrar o comportamento de acoplamento (coupling) entre duas configurações aleatórias ao longo do tempo. Para isso, são utilizadas bibliotecas como NumPy para manipulação eficiente de vetores, Matplotlib para a construção da interface gráfica e animação.

Inicialmente, é definido um tamanho fixo \textit{TAM}=50, que representa o número de posições do sistema. Cada posição pode assumir um valor de "spin", isto é, $+1$ ou $-1$, o que remete ao modelo de Ising. Duas configurações independentes são criadas a partir da classe Configuracao, uma iniciada com todos os spins positivos e outra com todos negativos. Essas configurações são armazenadas como listas, e sua representação visual é feita por meio de pontos (as "bolinhas") no gráfico.

Um ponto central do código é o uso de atributos de classe, como \textit{icouple} e \textit{disponiveis}. O conjunto \textit{icouple} armazena os índices das posições onde as duas configurações coincidem, ou seja, onde já ocorreu o acoplamento. Esse mecanismo é essencial para o entendimento do código, pois, uma vez que duas posições forem acopladas, suas evoluções futuras passam a ser sincronizadas.

A dinâmica do sistema é implementada no método andar, que representa um passo temporal da simulação. A cada iteração, dois índices aleatórios são selecionados. Para cada configuração, o valor do spin nesses índices é atualizado de forma aleatória. Porém como dito anteriormente, se o índice já pertence ao conjunto icouple, a atualização é feita de forma conjunta nas duas configurações, garantindo que permaneçam iguais naquela posição. Caso contrário, as atualizações ocorrem de maneira independente. Após essa etapa, o algoritmo verifica novamente todas as posições para identificar novos acoplamentos.

O metodo visualizar desempenha um papel fundamental na compreensão do processo. O método visuaizar utiliza cores para indicar o estado de cada posição: vermelho e preto representam spins positivos e negativos, respectivamente, enquanto verde indica posições onde ocorreu acoplamento. Assim, ao longo da animação, é possível observar a propagação gradual dessas regiões verdes, evidenciando a convergência entre as duas configurações.

A animação é controlada pela função update, utilizada em conjunto com a classe FuncAnimation do Matplotlib. A cada quadro, o tempo é incrementado e um novo passo da dinâmica é executado. O processo continua até que todas as posições estejam acopladas, isto é, quando o tamanho do conjunto icouple atinge \textit{TAM}. Nesse momento, a simulação é interrompida e são exibidas informações relevantes, como o tempo total necessário para o acoplamento completo e uma estimativa teórica baseada em \textit{TAM $\cdot$ log(TAM)}, que é teorizada pelo Teorema \ref{thm:teorema_1}.

\subsection{Metaestabilidade: Uma abordagem com potêncial}

\begin{figure}[H]
	\centering

	\caption{Andar mestaestável com 4 estados}

\end{figure}

O código apresentado implementa uma simulação de passeio aleatório em uma estrutura de grafo especialmente construída para evidenciar o fenômeno de metaestabilidade. A modelagem combina conceitos de probabilidade, grafos e visualização computacional, utilizando bibliotecas como \textit{NumPy}, \textit{Matplotlib} e \textit{NetworkX}. A ideia central é representar o espaço de estados como uma rede de regiões conectadas (os "cubos"), mas com poucas conexões entre si, o que induz um comportamento típico de sistemas metaestáveis: longos períodos de permanência em uma região antes de transições raras para outra.

A classe \textit{MetastableRandomWalk} é responsável por construir e gerenciar essa estrutura. No método '\textit{\_grafo}', o espaço de estados é definido como um grafo composto por quatro "cubos" (d)-dimensionais, cada um contendo ($N^{d}$) vértices. Cada vértice representa um estado possível do sistema e é identificado por um rótulo que indica tanto o cubo ao qual pertence quanto sua posição interna. A conversão entre índices lineares e coordenadas multidimensionais é tratada pelos métodos '\textit{\_indexCoord}' e '\textit{\_coordIndex}', permitindo organizar os vértices como se estivessem em uma grade discreta.

Dentro de cada cubo, os vértices são conectados aos seus vizinhos imediatos, formando uma malha regular. Essa densa conectividade interna garante que o passeio aleatório se mova facilmente dentro de um mesmo cubo. Por outro lado, o método '\textit{\_JuntarCubo}' cria apenas algumas conexões específicas entre cubos distintos, ligando pontos de canto. Essa escolha é crucial: ela cria "gargalos" estruturais no grafo, dificultando a transição entre regiões diferentes e, consequentemente, gerando o comportamento metaestável.

A dinâmica do passeio aleatório é definida de maneira simples e clássica. O método '\textit{inicio}' escolhe um estado inicial dentro de um cubo específico, com uma restrição adicional, o ponto deve estar em uma região mais central do cubo, evitando bordas. Essa escolha reforça o efeito metaestável, pois aumenta a probabilidade de o sistema permanecer inicialmente dentro do mesmo cubo. Já o método '\textit{andar}' implementa o passo do passeio aleatório, no qual o próximo estado é escolhido uniformemente entre os vizinhos do estado atual.

A trajetória do sistema é armazenada ao longo do tempo, permitindo acompanhar o caminho percorrido. Esse registro é essencial para a visualização e para a análise do comportamento do processo. O método '\textit{simular}' apenas automatiza a execução de múltiplos passos consecutivos, retornando a sequência de estados visitados.

A visualização é tratada pela classe '\textit{visualizar}', que constrói uma representação bidimensional do grafo. O método '\textit{\_nodeCoord}' projeta os diferentes cubos em posições distintas do plano, organizando-os como regiões separadas (norte, sul, leste e oeste). Isso facilita a interpretação visual das transições entre cubos. A função '\textit{setup\_plot}' desenha os nós e arestas, diferenciando as conexões internas (em cinza) das conexões entre cubos (em vermelho tracejado), além de configurar elementos como legenda e título.

A animação é controlada por meio da função '\textit{animate\_step}', que atualiza, a cada quadro, tanto a posição atual do passeio quanto o caminho acumulado. O ponto vermelho indica o estado atual, enquanto a linha azul mostra a trajetória já percorrida. Informações adicionais, como o número do passo, o cubo atual e as coordenadas internas, são exibidas dinamicamente. A utilização de '\textit{FuncAnimation}' permite observar em tempo real a evolução do sistema.

Do ponto de vista conceitual, o código ilustra de forma clara o fenômeno de metaestabilidade: o passeio aleatório tende a permanecer por longos períodos dentro de um mesmo cubo (devido à alta conectividade interna), realizando apenas ocasionalmente transições para outros cubos (devido às poucas conexões entre eles). Esse comportamento é característico de sistemas com múltiplos ?poços de energia? ou regiões de estabilidade local, sendo amplamente estudado em áreas como física estatística, teoria das cadeias de Markov e algoritmos de amostragem.

import numpy as np
import matplotlib.pyplot as plt
from collections import defaultdict
import networkx as nx
import math
from matplotlib.animation import FuncAnimation

class MetastableRandomWalk:
    def __init__(self, N, d=2):
        self.N = N
        self.d = d
        self.EN = self._grafo()
        self.estadoAtual = None
        self.passo = 0
        self.caminho = []
    
    def _grafo(self):
        G = nx.Graph()
        # Cria os 4 cubos (E0, E1, E2, E3)
        cuboPonto = {}
        
        # Para cada cubo (0: norte, 1: leste, 2: sul, 3: oeste)
        for cubo in range(4):
            cuboPonto[cubo] = []
            
            # Gera pontos do cubo d-dimensional da vez cube
            for i in range(self.N**self.d):
                coords = self._indexCoord(i)
                NodeId = f"{cubo}_{i}"
                G.add_node(NodeId, cubo=cubo, coords=coords)
                cuboPonto[cubo].append(NodeId)
        
        # Conecta as vizinhas de cada cubo dentro de cada curbo,
        #mas não os pontos de intersecção
        for cubo in range(4):
            points = cuboPonto[cubo]
            for i, nodeOrin in enumerate(points):
                coords1 = self._indexCoord(i)
                # Encontra vizinhos no cubo
                for dim in range(self.d):
                    for delta in [-1, 1]:
                        vizin = coords1.copy()
                        vizin[dim] += delta
                        if 0 <= vizin[dim] < self.N:
                            j = self._coordIndex(vizin)
                            node2 = points[j]
                            G.add_edge(nodeOrin, node2)
        
        # Conecta cubos adjacentes (pontos de canto compartilhados)
        self._JuntarCubo(G, cuboPonto)
        
        return G
    
    def _indexCoord(self, index):
        #Converte índice linear para coordenadas d-dimensionais
        coords = []
        vindex = index
        for _ in range(self.d):
            coords.append(vindex % self.N)
            vindex //= self.N
        return coords
    
    def _coordIndex(self, coords):
        #Converte coordenadas d-dimensionais para índice linear
        index = 0
        potDim = 1
        for i, coord in enumerate(coords):
            index += coord * potDim
            potDim *= self.N
        return index
    
    def _JuntarCubo(self, G, vCuboPontos):
        #Ajunção dos cubos
        conecta = [(0, 1), (1, 2), (2, 3), (3, 0)]  
        # pares de cubos adjacentes
        
        conectaPonto = [(self.N-1, 0), 
        (0, self.N-1), (0,0), (self.N-1,self.N-1),
        (0, self.N-1), (self.N-1, 0), (self.N-1, self.N-1), 
        (0, 0)] #Quem queremos ligar
        
        for i in range(0,8,2):
            pontos1 = vCuboPontos[conecta[int(i/2)][0]]
            pontos2 = vCuboPontos[conecta[int(i/2)][1]]
            
            indexNode1 = self._coordIndex(conectaPonto[i])
            indexNode2 = self._coordIndex(conectaPonto[i+1])

            print(indexNode1, indexNode2)

            G.add_edge(pontos1[indexNode1], pontos2[indexNode2])

    def inicio(self, start=0):
        #Inicializa o passeio aleatório em um cubo
        cuboPontos= [node for node in self.EN.nodes 
        if self.EN.nodes[node]['cubo'] == start]
        procurando = True
        while(procurando):
            procurando = False
            self.estadoAtual = np.random.choice(cuboPontos)
            for i in range(2):
                if(self.EN.nodes[self.estadoAtual]['coords'][i] > self.N - 
                ( math.floor( math.sqrt(self.N) ) )/2 ): 
                #para começar no quadrado interno
                    procurando = True
                    break
                elif(self.EN.nodes[self.estadoAtual]['coords'][i] < 
                ( math.floor( math.sqrt(self.N) ) )/2 ):
                    procurando = True
                    break
        self.passo = 0
        self.caminho = [self.estadoAtual]

    def andar(self):
            vizin = list(self.EN.neighbors(self.estadoAtual))
            self.estadoAtual = np.random.choice(vizin)
            self.passo += 1
            self.caminho.append(self.estadoAtual)
            
            return self.estadoAtual

    def simular(self, steps, start=0):
            self.inicio(start)
            
            for _ in range(steps):
                self.andar()
            
            return self.caminho

    def _nodeCoord(self):
        #Calcula posições dos nós para visualização 2D
        pos = {}
        cuboMeio = {
            0: (0, self.N + 1),      # Norte
            1: (self.N + 1, 0),      # Leste  
            2: (0, -self.N - 1),     # Sul
            3: (-self.N - 1, 0)      # Oeste
        }
        
        for node in self.EN.nodes:
            cubo = self.EN.nodes[node]['cubo']
            coords = self.EN.nodes[node]['coords']
            projX, projY = cuboMeio[cubo]
            pos[node] = (coords[0] + projX, coords[1] + projY)
            
        return pos

\subsection{Convergência de distribuição: Tempo de saída}

\begin{figure}[H]

	\caption{Convergência da distribuição do tempo de fuga de um estado}

Nesta simulação é apresentado a modelagem de um caminhar aleatório em uma malha bidimensional quadrada de tamanho $N \times N$, estruturada na forma de um grafo. A simulação afere o tempo de saida do estado (a malha) que a particula se encontra, e demonstra para qual convegência a distribuição da abservação desse evento tende. Diferente do modelo anterior que foi construido 4 malhas conectadas utilizando conceitos básicos de grafos, como nesse modelo temos somente uma malha, podemos utilizar o método '\textit{grid\_ 2d\_ graph}' da biblioteca '\textit{NetworkX}' para criar tal objeto. A descrição do modelo é a mesma do anteior, começando no meio do estado, transição uniforme, e com o tempo de termalização menor do que o tempo de chegar na borda para a transição de estado. Um ponto importe a se salientar sobre o código, é o método para indicar que a particula saiu do estádo é uma borda ao redor do quadrado $N \times N$, ou seja, o método cria um grid para \textit{N+1}, mas o estado é de \textit{N}, o resto é uma adaptação para representar a saída do estado. Por fim, para representar e verificar a comparação da convergência da distribuição, utilizamos o teorema de Glivenko-Cantelli para intuir no resultado da convergência, e na simulação utilizamos a bioblioteca '\textit{scipy.stats}', focada em probabilidade e estatística,para plotar o gráfico da Logística e realizar a comparação.

import numpy as np
import networkx as nx
import matplotlib.pyplot as plt
import math

class SingleCubeEscape:
    def __init__(self, N):
        self.N = N
        self.G = self._build_graph()
        self.reset()

        self.escapes = []   # tempos de saída
        self.attempt = 0

    def _build_graph(self):
        # Cria um grid NxN
        return nx.grid_2d_graph(self.N, self.N)

    def reset(self):
        self.passo = 0
        self.caminho = []
        mid = self.N // 2 # Começa sempre no centro
        self.estadoAtual = (mid, mid)
        self.caminho.append(self.estadoAtual)

    def is_boundary(self, node):
        x, y = node
        return x == 0 or y == 0 or x == self.N - 1 or y == self.N - 1

    def andar(self):
        vizinhos = list(self.G.neighbors(self.estadoAtual))
        self.estadoAtual = vizinhos[np.random.randint(len(vizinhos))]

        self.passo += 1
        self.caminho.append(self.estadoAtual)

        # Condição de escape
        if self.is_boundary(self.estadoAtual):
            # Normalização de escala para malha 2D
            fator_escala = ((self.N - 1) ** 2 * math.log(self.N - 1))
            self.escapes.append(self.passo / fator_escala)
            self.attempt += 1
            self.reset()

    def simular(self, tentativas):
        for i in range(tentativas):
            while True:
                self.andar()
                if self.attempt > i:
                    break
            print(f"Tentativa {i+1}/{tentativas} concluída.")
        return self.escapes
